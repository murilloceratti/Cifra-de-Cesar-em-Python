# 🔐 Cifra de César 

Implementação de uma ferramenta de criptografia em Python baseada na clássica **Cifra de César**, executada via terminal.

O objetivo do projeto é aplicar fundamentos de lógica de programação e simular um sistema simples de criptografia simétrica.

---

## ⚙️ Funcionalidades

- 🔒 Codificação de mensagens (criptografia)
- 🔓 Decodificação de mensagens (descriptografia)
- 🧭 Menu interativo no terminal
- 🔤 Suporte ao alfabeto (a-z)
- ✳️ Preserva espaços e caracteres especiais
- 🎨 Interface estilizada com `colorama`
